# Frozen experiment records

These files are byte-for-byte copies of selected local reports/manifests,
except for the generated `index.json`. They preserve the strongest positive
result, the linear negative control, the failed/mixed nonlinear confirmation,
and the latest transient Navier--Stokes numerical gate.

The records deliberately retain original artifact paths and SHA256 values.
Those paths describe the machine on which the experiment ran and are not
expected to exist in a fresh Git checkout.
