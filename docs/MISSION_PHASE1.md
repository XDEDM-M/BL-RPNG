> 用法：将本文件放入项目 `docs/MISSION_PHASE1.md`，只把第 0 节启动提示词发给 Codex。

## 1. 总目标与研究立场

### 1.1 最重要的目标

围绕下列使用场景建立有竞争力的主方法：

1. 数据集 A：多个非齐次 Dirichlet 边界条件下的 HR rollout 与真实 Newton 中间轨迹，用于预训练。
2. 数据集 B：源训练未见的目标边界条件下，少量独立生成的 LR rollout 与 Newton 轨迹，用于适配。目标间可以各自适配。
3. 推理：适配后输入 HR 物理场并进行时间自回归，用目标任务独立 HR rollout 评价。
4. 比较：充分调优的 LR scratch、普通预训练后 LR 适配，以及 HR 数据训练的强专家。

主问题是：**学习求解器的中间过程，能否让网络以更少的新边界数据、更低的新增成本，达到有竞争力的 HR 精度？**

FNO 可以在不同网格上计算，不代表精度自动跨分辨率保持；必须实测。Newton 的一般求解框架也不自动赋予神经网络普适泛化能力。

### 1.2 对实验效果的明确要求

- 学习率、优化器、调度器、训练时长、损失权重、路径层映射、归一化、微调范围、正则化、课程学习等都是可用的研究工具。
- 不因“收益可能来自调参”就停止优化。先获得强方法，再用同预算比较和消融解释收益。
- 同时保留两张表：**各方法独立调优后的最佳性能表**，以及**固定骨干与共同训练配置的机制对照表**。前者回答谁更好，后者回答为什么。
- 方法特有的技巧可以用于主模型，但必须标明；通用技巧至少给最强直接竞争基线验证机会。
- 不能承诺一定获得正面结果或某级别发表。任务要求是在有限资源内尽最大努力获得优秀结果，并留下真实证据。

### 1.3 当前结果与优先顺序

用户提及的“相对 lifted scratch 提升 88.23%”、原方案中的“48 任务”“5.2% 差距”，一律视为**待核实历史线索**。核实指标、协议、样本与文件之前，不写入正式结论。

默认优先推进仓库已有成熟数据和强结果对应的 PDE。若是 Allen–Cahn，则先做强该实验；NS 为后续重要方向，但不能让重型 NS 生成挤占本阶段主结果优化。瞬态 NS 保持时间自回归定位；稳态参数延拓只作补充。

| 优先级 | 本阶段要解决的问题 | 交付 |
|---|---|---|
| P0 | 最优训练与微调策略能否进一步降低目标 HR rollout 误差？ | 最优配置、检查点、完整优化记录 |
| P0 | 少样本 LR 适配能否接近 HR 专家，同时明显优于强 LR 基线？ | 多种子主表、样本效率曲线 |
| P1 | 新边界数据生成、适配与推理是否具有真实成本优势？ | 成本表、盈亏平衡与帕累托图 |
| P1 | 路径信息是否提供超过终点辅助监督的收益？ | 最小充分机制对照 |
| P2 | 求解器热启动、第二 PDE、更多骨干是否值得扩展？ | 触发条件满足后的小规模证据 |

## 2. 不可违反的规则与可调整的空间

### 2.1 数据与评价纪律

1. 不修改冻结的数据划分、测试集与历史结果。新训练和新协议放新目录，不覆盖旧检查点；不无关修改原项目。
2. 完整 rollout、初始条件和边界任务是划分单位，不能随机拆时间帧造成泄漏。明确边界“参数未见”和“函数族未见”两个层次。
3. 目标任务 LR support 与 HR query 初始条件独立；边界和物理参数配对，物理时刻对齐。B 必须包含真正粗网格求解数据，不能用 HR 下采样冒充低成本生成。
4. 归一化只使用源训练数据或部署允许的 LR support；不得用 query/测试统计量。保存统计量的来源。
5. 超参数与早停只看训练/验证。历史测试结果可用于复现，不能据此反复选模型；被反复观察的历史 blind 集标记为历史评测集，并为新确认建立独立测试任务。
6. 开发期允许用独立开发边界上的 HR 验证评价跨分辨率设计；最终测试边界不得用于全局超参选择。实际新任务的适配与早停只用 LR support/validation，或预先固定的部署规则。
7. 将“每个目标有 HR 验证标签”的方案单列为诊断上限，不能混进“仅 LR 适配”的核心结果。
8. 所有数字来自真实输出。失败、发散、负面结果和全部 trial 保留；失败率单列，不把崩溃伪装为普通误差样本。

### 2.2 路径信息必须真实

- 保存或核实 accepted Newton states/corrections、残差、自然初猜、最终解与路径选取规则。
- 设求解器真实初猜为 `q0`，终点 `q*`，第 k 个 accepted 状态为 `qk`。用同一初猜定义 `Δ*=q*−q0`、`Δk=qk−q0`，报告 `Dk=||Δk−Δ*||/(||Δ*||+ε)`。
- 同时报告幅值比、夹角和第 k 步索引；`ε` 规则预先固定，对终点增量近零样本单独处理。向量 PDE 的速度、压力应分别统计，避免混合尺度。
- 若 `q0` 不等于当前物理状态 `u_t`，明确两者关系，禁止把 Newton 更新与物理时间增量混为一谈。
- 不仅看 D：若 `Δk≈αΔ*`，仍可能只是终点缩放。追加最优线性投影残差，检查路径偏离终点方向的程度。
- 不通过人为劣化初猜、放宽收敛容差制造路径。调整 dt/非线性强度时必须同时保物理精度与原任务意义。
- 对非齐次边界，确认 lifting 与预测修正的零边界约束，路径标签在同一表示空间；时变边界必须考虑每个时间步的 lift。

### 2.3 探索与确认分开

探索阶段运行前只需写简短实验卡：目的、配置、预算、验证指标、比较对象。允许根据验证结果迭代，不必为每次调学习率写长篇预注册。

确认阶段在 `docs/prereg/CONFIRMATORY.md` 冻结：任务集合、support 数量与抽样规则、随机种子、checkpoint 选择、核心指标、成本口径与成功目标。之后只追加 amendment，不回写原记录。

不需要一次跑完所有超参组合。使用随机搜索/现有搜索工具、逐级淘汰和局部细化；避免巨大笛卡尔积。

### 2.4 公平比较

- 机制对照：固定架构、数据、共享超参和训练预算，唯一变化为辅助监督内容；同时测无辅助监督。
- 性能对照：各方法独立调优，共享超参使用相同合理范围，方法特有参数使用各自范围；预先分配可比的 trial 数与 GPU 时预算，分别报告实际消耗。
- 不能要求不同方法有完全一样的特有搜索空间，也不能把 trial 数相等当成算力相等。
- 现有主方法历史搜索投入如能追溯应列出；无法追溯时披露限制，不能声称历史总预算严格相等。
- 基线明显未收敛时先补训练/调参，不能将其作为核心性能比较对象。

## 4. 按优先级执行的实验方案

执行顺序：**Stage 0 → Stage 1 → Stage 2 → Stage 3 → Stage 4（条件触发）**。

### Stage 0：轻量发现与可信起点

目标：尽快知道现有最好结果在哪里、主要短板是什么，不启动全面审计工程。

**E0-a 仓库发现：** 阅读 README、实验进度、理论说明及必要代码。生成简短 `docs/audit/REPO_MAP.md`，定位生成、预训练、路径标签、适配、评价及现有最优配置。NLT 等缩写以代码为准。

**E0-b 核实当前最好结果：** 优先重算保存的预测/指标和 manifest；必要时跑已有 checkpoint 的评测。区分历史复算与新确认，不为“复现”反复打开新的 blind 集。

**E0-c 最小关键检查：** 数据泄漏、LR 是否真正求解、HR/LR 时刻对齐、路径标签是否近终点重复、lift/归一化是否一致、支持集与查询是否独立。只有会改变主结论的问题阻断后续；其他问题记入 backlog。

**E0-d 确定主协议与预算：** 选择成熟 PDE、开发/确认边界集合、主分辨率对和样本单位。m 默认指独立 support rollout 数，不指时间帧数。记录实际任务数量，禁止硬套“48”。

**Gate 0：** 有可运行且可信的基线和主方法；不存在已知重大泄漏/指标错误。若只有部分历史资产缺失，可建立明确标注的新基准，不以无限追查旧资产替代新实验。

### Stage 1：把主方法优化到当前资源允许的强水平（最高优先级）

**E1：三个连续改进轮次**

| 轮次 | 重点 | 优先尝试 |
|---|---|---|
| R1：训练与适配优化 | 先兑现已有方法潜力 | 学习率/调度、训练充分性、梯度裁剪、路径权重与衰减、微调参数范围 |
| R2：跨分辨率与 rollout | 针对主要误差来源改进 | 源 HR/LR 混合预训练、分辨率一致性、短到长 rollout 损失、跨网格归一化 |
| R3：路径表征 | 检查求解器信息如何更有效进入模型 | 首个非冗余 accepted 更新、层-hook 映射、少量多节点监督、更新方向/幅值分开建模 |

每轮至少实施并实际运行一个有证据依据的改进；允许有效候选累积组合，但最终做必要的剥离消融。若可复用既有完整结果，则记录资产并减少重复计算。

R1 先从仓库真实最优配置起步。历史出现过的 `layer1:hook0`、`λ_path=0.01/0.1` 和权重衰减只是候选线索，不能跨 PDE 直接指定为最优。

推荐局部搜索：学习率以当前最好值的 {0.3,1,3} 倍；路径权重含 0 对照及当前值附近的对数尺度；比较常数/衰减权重；微调比较现有适配器、选定层与全量微调。宽度、modes、深度只在容量不足有证据时调整。

**必须包含一次真实 LR 路径微调对照：** 同一预训练初始化下，比较目标端 final-only 适配与目标端 path-guided 适配。路径权重、监督层、学习率和训练时长共同调优；若原 NLT 实现不能挂路径头，做最小兼容实现，而非默认当前 NLT 就是路径微调。

如拟使用残差/物理损失，先确认可在 LR 部署中计算且不依赖 HR 标签；数值残差算子跨分辨率一致性要实测。EMA、早停、课程学习等通用技巧可试；集成结果单列并计入推理成本。

**E1 的搜索节奏：**

1. smoke：验证 shape、反向传播、边界、LR→HR 推理和日志，不能用短跑排名作结论。
2. 单种子筛选：最多 24 个主方法 trial；初期用代表性开发任务筛选。
3. 短名单：2–3 个候选在完整开发集合、至少 3 模型种子上训练；记录长 rollout 与最差边界族表现。
4. 晋级：按预先记录的开发 HR rollout 主指标选择；同时观察尾部失败率和成本。保留 champion 与次优配置。

**诊断先于下一轮：** 若无提升，先判定欠拟合/过拟合、路径梯度冲突、路径冗余、适配容量或 LR→HR 误差；不盲目增宽网络、不反复仅换种子。

**Gate 1：** 三轮优化有实际结果和决策；或提前已达性能目标并在 ≥3 模型种子上稳定成立。即使三轮无收益，仍进入 Stage 2 确认最强版本，不能直接结束。

### Stage 2：主结果、强基线与 HR 专家

**E2-a：核心主表**

| 方法 | 源预训练 | 目标 LR 适配 | 作用 |
|---|---|---|---|
| B0：lifted scratch | 无 | final-only，从头训练 | 实用 LR 基线 |
| B1：普通预训练 + FT | final-only | independently tuned final-only | 排除普通迁移收益 |
| B2：普通预训练 + path FT | final-only | 路径微调 | 隔离目标路径作用 |
| M0：路径预训练 + FT | path-guided | final-only | 隔离源路径作用 |
| M1：路径预训练 + path FT | path-guided | 路径微调 | 用户核心设想 |
| M*：优化后的主方法 | 最优设计 | 最优 LR 方案 | 最终性能系统 |
| H：HR 专家 | 从头/源初始化择优，分别报告 | 充足 HR 标签 | 经验性能参照 |

相同配置的重复方法合并，不浪费算力。B1 中适配方式至少比较现有 NLT 与全量微调；LoRA 已实现则加入，否则仅在容量/成本诊断需要时实现。

最强直接竞争基线获得与 M* 可比的新增搜索预算；其余因果臂优先使用共享配置，按需要局部调优。性能表必须清楚标注哪些是独立调优结果。

**E2-b：HR 专家曲线**

先选 4–8 个代表任务，覆盖较易/较难和未见边界族；同一 query 上逐级增加独立 HR 训练 rollout，分别训练 HR scratch 与 HR 全量适配专家。

固定验证选 checkpoint。默认每次数据量翻倍；连续两次翻倍验证误差改善不足 2%、且加长训练也无明显改善时，可标为“在已测预算下经验饱和”。达预算前未饱和则如实报告，不能称 oracle 下界；不得为了接近它故意削弱专家。

**E2-c：少样本曲线与泛化层次**

使用嵌套 support，m∈{1,2,4,8,16}；至少比较 M*、最强普通迁移和 LR scratch。筛选全曲线可用 3 种子，核心 m 的主表用 5 模型种子与 ≥3 support 抽样种子；若全集成本过高，明确主表与探索曲线的范围差别。

优先验证“未见边界函数族”；资源不足只能测试参数外推时，明确结论限于参数外推。补充零样本作为参照，但少样本适配才是核心任务。

**主指标：** 预先固定 rollout 长度，默认完整 20 步平均相对 L2；若任务实际长度不同则用实际协议。50 步仅在存在可信 HR reference 时追加。定义分母、空间权重、跨步/跨样本聚合方式；不能混淆平均逐步相对 L2 与整条轨迹相对 L2。

同时报告 one-step、最后时刻、边界/近边界误差、最差边界族、失败率。精确施加边界时边界误差接近零属结构属性，近边界内部精度更有区分力。

**统计：** 任务/边界族是泛化证据单位，种子是重复测量，不把时间步当独立样本。按数据结构做配对分层/多路 cluster bootstrap，固定共享 support 的配对关系；5 模型种子×3 support 种子是交叉重复，不当 15 个独立任务。报告95% CI；边界族过少时限制总体外推并展示逐族结果。

### Stage 3：成本核算与最小机制证据

**E3：实测成本与差距定位**

测量 LR/HR 数据生成、目标适配、单次 HR rollout 推理、直接 HR 求解、HR 专家数据+训练。同步 GPU、预热并重复计时；说明硬件、容差、线程、batch 与 I/O 口径。

目标新任务成本：`C_method(N)=C_LRdata+C_FT+N*C_inferHR`。
直接求解成本：`C_solver(N)=N*C_solverHR`。
仅当 `C_solverHR>C_inferHR`，计算 `N*=ceil((C_LRdata+C_FT)/(C_solverHR−C_inferHR))`；否则不存在该口径下的盈亏平衡。

将源预训练与超参搜索分别计入离线成本；同时给出新增任务成本和按任务数摊销后的全生命周期成本。另比较 HR 专家工作流。一次 HR 初值获取若有成本，作为共同成本或方法特有成本注明。不能从分辨率差推断“必然快很多”。

差距诊断先做便宜项：LR 求解插值→HR 的误差、零样本、LR vs HR 标签适配、全量 vs 适配器、restrict/predict 交换差。它们是诊断比较，误差一般不可相加；不强行画成可加的堆叠误差分解。

**E4：最小充分路径对照**

沿用 Stage 1 最优合理骨干，做以下同配置对照；最关键比较再对双方给予对称局部调参。

| 臂 | 辅助目标 | 回答 |
|---|---|---|
| A0 | 无辅助目标 | 路径整体是否有用 |
| A1 | 真实 accepted Newton 中间位移 | 真实路径 |
| A2 | 终点位移，使用相同 hook/辅助头 | 是否只是深监督 |
| A3 | 终点方向上的中间目标 | 非线性路径是否额外有用 |
| A4 | 样本错配路径，按量级/任务属性合理匹配 | 样本对应关系是否重要 |

先核实标签选取与损失归一化。固定比例 `pΔ*` 在平方损失与相应尺度/头变换下，可能与 A2 数学等价；不能把这样的 A3 当成独立强证据。若等价则合并，并比较按真实 accepted 中间位移范数匹配的终点方向目标，披露其信息来源与变换。

A4 优先作为便宜的负对照，无需与主方法一样巨额搜索；A2 与有效 A3 才是机制关键。先 3 种子，出现稳定收益或需支撑核心机制结论时扩为 5 种子。

可同时做“预训练路径开/关 × 微调路径开/关”的 2×2 分析，复用 B1/B2/M0/M1；不要重复训练已有匹配资产。

机制结果分类：A1 优于 A2/有效 A3，才支持额外路径信息；仅优于 A0 支持辅助监督有效。CI 与实际差异都报告，不把不显著当作等效，也不把样本相关性写成因果机制。

## 5. 性能目标、失败后的动作与条件性扩展

### 5.1 预先设定的追求目标（不是既有事实）

Stage 0 根据现有误差量级冻结下列默认目标，若调整写明依据；不能看到确认测试后改门槛。

| 层级 | 默认目标 | 表述边界 |
|---|---|---|
| T1：主方法进步 | 相对可信旧 champion，开发 HR rollout 误差下降 ≥10%，或成本更低且误差不增 | 优化收益 |
| T2：强迁移优势 | 相对充分调优普通迁移，确认平均误差下降 ≥15%，配对95% CI支持优势，且尾部无灾难退化 | 少样本边界适配优势 |
| T3：接近 HR 专家 | 在经验饱和专家子集，`r=err_M*/err_H≤1.2`，且报告绝对误差差距与 CI | “接近”需明示标准；不能仅凭比值称等效 |
| T4：新增成本优势 | 达到约定精度时新增成本 ≤ HR 专家工作流的20%；报告实际应用 query 数下对直接求解的优势 | 区分训练专家与直接求解两类比较 |

若有任务需求中的绝对容差，优先用该容差。正式宣称“与专家近似等精度”需要预设可接受差距与相应等效/非劣检验，不能拿 r 阈值代替统计结论。近零专家误差时同时看绝对差，避免不稳定比值。

上述是雄心目标；未达标时必须优化和解释，但不无限搜索、不篡改数据，也不能据此保证论文等级。

### 5.2 结果不理想时的强制改进动作

| 诊断 | 优先动作 | 不得替代为 |
|---|---|---|
| 旧最优无法复现 | 核对版本、指标、数据、checkpoint；恢复可信起点 | 直接继续堆新实验 |
| 相对普通迁移优势弱 | 检查路径冗余、源/目标路径开关、梯度比例与 schedule；至少尝试一项路径表征改进 | 马上删掉路径主线 |
| HR 专家差距大 | 检查 LR 离散偏差、分辨率一致性、适配容量和 rollout 稳定性；先解决最大项 | 宣称 FNO 分辨率无关所以没问题 |
| 普通迁移比主模型强 | 给予主模型对称调参机会，检查路径造成的负迁移；比较仅预训练路径/仅微调路径 | 换一个弱基线 |
| 成本优势不明显 | profile 数据生成/适配/推理；减少适配参数与步数，做缓存和批处理并复测 | 根据网格数估算加速 |
| 少数边界崩溃 | 保留该族，检查 lift/幅值/频率与时间尺度，尝试按族均衡训练 | 删掉难任务 |

至少完成规定的三轮优化，或提前稳定达标；每轮留下可重算的结果。预算内连续两轮没有实质收益时可换诊断方向，不强求重复同一路线。

### 5.3 条件性扩展（不是 Phase-1 停止的前置清单）

1. **热启动：** 已有兼容求解器即可低成本测试自然初猜、普通 FNO、主方法预测作为初猜；用相同残差/物理精度标准，记录含网络推理的墙钟。新初猜可能落入不同非线性解分支，须核对最终物理解而非仅看残差。
2. **闭环学习步：** 只有热启动/残差诊断显示潜力、全 accepted 路径可得且主表完成时，做小原型。safeguard 保留真 Newton 回退，精度与收敛仍需实际验证；仅残差上升回退并不自动保证全局收敛或解误差。
3. **非冗余度规律：** 先用已有自然变化统计 D 与收益。只有明显信号时新增物理可信工况；不要为得到正相关专门选择有利数据点。
4. **第二 PDE/骨干：** 主方法已有稳定优势才扩展；机制仍薄弱则先补关键对照。NS 若开展，保留自然 `u_t` 初猜，审计时间精度、不可压和路径非冗余；沿用已确认的安全生成约束。

“所有 E1–E11 都跑完”不再作为本阶段要求。高优先级主表与优化证据完整后，再根据剩余预算决定扩展，避免把论文主张拉散。

### 6.2 允许结束的情况

**A. 成功完成：** 核心清单完成，预设精度/成本目标达到或主要目标有稳定证据；提交最终报告。

**B. 充分执行但目标未达：** 已完成规定优化轮次、关键比较和预算内合理搜索，核心清单完整；提交真实 NOT_MET 报告，说明最佳差距、已尝试路线和证据。不能称成功，也不能以第一次失败结束。

**C. 硬预算耗尽：** 完成或停止运行中作业，保留全部已完成结果和恢复入口，提交 `PARTIAL_BUDGET_EXHAUSTED`；列明缺项，不能伪装完成。不擅自超出预算。

**D. 真实外部阻塞：** 无法自行获得的数据/权限/算力或不可替代信息。可自修的 bug、未知最佳超参、子代理不可用、上下文压缩均不算外部阻塞。先继续不依赖该阻塞的工作。

普通训练时间长不能用“等完成后再说”交接；任务书不会赋予超出平台能力的持续执行。若会话/运行环境强制中断，写入 `PARTIAL_RUNTIME_LIMIT`，记录活跃作业与准确恢复命令，不声称全部完成。

1. `reports/PHASE1_FINAL.md`：最强主结果先行，包含主表、m曲线、HR专家差距、成本、机制结论与限制；每个数字链接原始证据。

3. 可复现运行脚本、配置和分析脚本；图表、日志、数据与大权重保留可访问路径。
4. `docs/PHASE1_COMPLETION.md`、`docs/STATE.md`、`docs/LOG.md`与完整trial ledger。
5. `docs/DECISION_MEMO.md`：据证据选择主线，不先许诺期刊等级：
   - 路径同时增强源预训练和目标适配，且接近专家：突出求解器信息迁移与低成本适配。
   - 性能强但额外路径机制证据弱：突出经充分优化的边界适配系统，限制Newton机制主张。
